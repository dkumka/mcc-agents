# Состояние проекта

Обновлено: 2026-11-23.

## Готово (v0.1)

- Демон `mcc-agentd` и веб `mcc-agents-web` на сервере, сайт https://agents.mcc.babochkin.com.
- Claude и Codex: новый чат, продолжение любого чата (в том числе созданного в терминале или CloudCLI), очередь сообщений,
  прерывание, подтверждения (разрешить / на сессию / всегда / отклонить с комментарием), вопросы `AskUserQuestion`,
  план `ExitPlanMode`, смена модели / усилия / режима на лету.
- Карточки: команды (живой хвост вывода), правки и записи с diff, чтение, поиск, веб, MCP, skills, субагенты (вложенные шаги),
  список задач (TodoWrite / план Codex), мысли.
- Фоновые задачи Claude: список, живой вывод, остановка.
- Контекст (% и токены), лимиты подписок (Claude: 5 часов / неделя; Codex: неделя), тариф.
- Слэш-команды и skills из CLI, `@` — поиск файлов проекта, картинки (вставка, перетаскивание, с телефона — с уменьшением).
- Правая панель: изменения git (diff по файлам), файлы проекта, фоновые задачи.
- Закрепление, переименование, непрочитанные, поиск чатов, группировка по проектам.
- Telegram: вопросы и подтверждения, на которые не ответили в вебе; «Готово» — только если попросить для чата
  (меню чата → «Сообщить в Telegram, когда закончит», с 2026-11-18).
- Светлая и тёмная тема; мобильная версия проверена в iOS Simulator (iPhone 17 Pro, Safari) и на 375 px.
- Сессии общие с терминалом в обе стороны (`claude --resume` видит веб-чаты благодаря `CLAUDE_CODE_ENTRYPOINT`).

### v0.2 (2026-11-12)

- Вход формой (`mcc-auth`, общий для домашней, агентов, VS Code, терминала) вместо basic auth.
- Тема: светлая по умолчанию / тёмная, в cookie, без мигания; переключатель на два состояния.
- Ширина левой и правой панелей меняется перетаскиванием (с ограничениями), запоминается.
- Просмотр файлов: подсветка Shiki, перенос строк (переключатель), то же для diff.
- Окно «Настройки»: задержка отправки подтверждений в Telegram (по умолчанию 1 мин), тема, выход.
- Подтверждения/вопросы/план в Telegram с кнопками и синхронизацией с вебом (бот агентов подключён, проверено `scripts/tg-test.mjs`).

### v0.3 (2026-11-12)

- Приложение на экране «Домой» iOS: шапка под строкой статуса (без размытия Liquid Glass), правильная высота экрана и клавиатуры,
  новые иконки (в т.ч. maskable), полноценный manifest, кнопка «Обновить». Проверено в iOS 26.2 (iPhone 17 Pro) в режиме веб-приложения.

### v0.4 (2026-11-12)

- Любые файлы во вложениях (Word, Excel, PDF, архивы…, до 50 МБ): загрузка с прогрессом, агент получает путь и читает сам.
  Проверено: Claude и Codex дословно прочитали .docx. Поле ввода над клавиатурой на iOS 27 (проверено пользователем).
- Вложения хранятся бессрочно; оригиналы картинок тоже сохраняются. Любой файл открывается по нажатию в просмотрщике
  (картинки, PDF, видео, текст/код; Word/Excel — карточка), «Скачать» и «Поделиться» (iPhone: сохранить в «Файлы», открыть
  в Word/Pages). Пути к файлам в ответах агента и в карточках правок кликабельны. «Настройки» показывают объём вложений,
  панель «Файлы» — кнопку «Вложения». Не проверено на самом iPhone: «Поделиться», PDF-карточка, скачивание из приложения на
  экране «Домой».

### v0.5 (2026-11-12)

- Режимы «Чат | Код»: беседы вне проектов (своя папка `~/chat/<дата>-<id>` на каждую, Claude Opus по умолчанию, «Авто»),
  список бесед по датам. Правила сервера у Claude больше не глобальные — подключаются только в `~/dev`. Проверено:
  Claude и Codex в беседе, файл из беседы открывается по нажатию, в беседе Claude правил сервера не видит, в проектах — видит.
- Непрочитанные: отметка общая для всех устройств (`lastSeen` на сервере). Время изменения чата двигает только ход
  (начало, подтверждение, конец, ошибка), а не запуск/закрытие процесса; у Claude — по последнему сообщению в `.jsonl`,
  а не по mtime (CLI при выходе дописывает служебные строки `cost-state`, `session-owner`…). Раньше прочитанные чаты
  снова становились непрочитанными через 20 минут, когда закрывался простаивающий процесс.

### v0.6 (2026-11-13)

- Голосовой ввод: кнопка 🎤 в поле, распознавание через OpenRouter (4 модели на выбор в настройках, по умолчанию
  MAI-Transcribe 2), режим «отправлять сразу». Проверено в Chrome (запись подменена тестовой фразой) и в вёрстке 375 px;
  на iPhone (Safari, приложение на экране «Домой») — нет.
- Голосовой ввод, часть 2: исправление текста LLM (убирает «э-э» и повторы, английские слова латиницей), галочка
  «Переводить на английский», записи хранятся на сервере (повтор распознавания любой моделью, «Очистить всё»), тост
  «Повторить» при ошибке, вкладки в настройках. Проверено в Chrome на синтезированной диктовке.
- Телефон: чипы модели / глубины / режима в поле ввода компактные (короткие подписи без стрелок), 🎤 и «Отправить» видны
  всегда (проверено на 375 и 320 px, Claude и Codex); во время записи «Закончить» — на месте «Отправить».
- Во время ответа можно листать вверх: любое движение вверх отключает прилипание к низу, пока палец на экране — список не
  прокручивается; прилипание возвращается внизу, по «Вниз» или при отправке своего сообщения.
- Непрочитанные чаты не «оживают» от закрытия процесса; codex app-server не перезапускается при остановке демона.

### v0.7 (2026-11-16)

- Новый проект в `~/dev` из интерфейса (по желанию — git), сразу чат в нём.
- Время сброса лимитов (5 часов / неделя) — карточка по наведению или нажатию.
- Форк чата с выбором названия (из меню или с любого своего сообщения) и откат разговора к сообщению с «Вернуть как было».
  Только диалог, файлы не трогаются. Claude и Codex, проверено в браузере.

- «Авто» — режим подтверждений по умолчанию (новые чаты, чаты из терминала, бывшие «Спрашивать»); подпись модели
  Opus 5.5 больше не путается с «Opus 5».

- Мягкий архив чатов и бесед: раздел «Архив» в левой панели, меню строки (наведение / правый клик / долгое нажатие).

### v0.8 (2026-11-18)

- «✅ Готово» в Telegram больше не приходит само — только если попросить для конкретного чата (меню чата → «Сообщить
  в Telegram, когда закончит», колокольчик в шапке; срабатывает один раз). Вопросы и подтверждения без ответа в вебе
  приходят как раньше. Каждое уведомление пишется в журнал демона (`hub: notify …`).
- Дополняющие сообщения посреди хода: агент получает их сразу, чат больше не зависает в «Работает» (учёт по
  `command_lifecycle`); «Стоп» не может зависнуть.
- Выкатка: `scripts/sync.sh` после копирования файлов запускает на сервере `scripts/git-align.sh` — git переходит на
  `origin/main`, если файлы совпадают, иначе выводится список незакоммиченных файлов и git не трогается. Раньше на сервере
  копились «изменённые файлы» и отказывал `deploy.sh`.

### v0.9 (2026-11-23)

- **Antigravity (`agy`) — третий агент наравне с Claude и Codex**, через официальный `agy acp` (Agent Client Protocol —
  тот же вход, что у Zed и JetBrains). Новый чат и беседа, продолжение разговоров из терминала (`agy --conversation <id>`
  открывает тот же), история, мысли, карточки команд и правок с diff, подтверждения, дополнения посреди хода, «Стоп»,
  модели (Gemini 4 Neon / Argon / Hydrogen, Flash, Orchestrator, Claude, GPT-OSS) с глубиной размышлений, режимы,
  слэш-команды, контекст, тариф внизу панели. Проверено на сервере: сквозной тест (подтверждение, вывод, второй ход),
  загрузка истории, дополнение посреди хода («FIRST SECOND» одним ответом), «Стоп»; в браузере — новый чат, подтверждение,
  терминальная беседа, вёрстка 375 px. На iPhone не проверено.
- По умолчанию у Antigravity «Правки без вопросов»: режима «Авто» agy на этом сервере не даёт (нужна его песочница, её
  запрещает AppArmor) — команды он спрашивает. Форков, откатов и остатка лимитов в ACP нет — в вебе они скрыты.
- Карточки выбора агента: три в ряд, на телефоне значок над названием. Исправлено: после перезагрузки выделялся Claude,
  хотя выбран был последний агент (ошибка гидратации, была и с Codex). Чип глубины показывает уровень, который у модели
  есть на самом деле. На телефоне подписи моделей Antigravity короче («4 Neon», «OSS 120B»), чтобы строка поля ввода помещалась. `AGENTD_TELEGRAM=0` — тестовый экземпляр демона не трогает Telegram-бота.
- Позже в тот же день: у Antigravity появился режим **«Авто»**, и он стал режимом по умолчанию (новые чаты и чаты, где режим
  не выбирали). Для этого на сервере точечный профиль AppArmor `/etc/apparmor.d/agy`: только agy можно создавать свою
  песочницу, для остальных программ запрет Ubuntu остаётся. Проверено: Auto в списке режимов, команда в Auto выполнилась
  без вопроса внутри песочницы agy (свои user/mnt namespaces).
- Выкатка: `deploy.sh` решал, перезапускать ли демон, по разнице «git до / после», а `sync.sh` (git-align, 2026-11-18) уже
  переводит git на новый коммит — изменения демона не перезапускали его (так было с этим исправлением; то же грозило
  `npm install`). Теперь `deploy.sh` помнит, с какого коммита собран веб и запущен демон (`.git/mcc-deploy/`), и сравнивает
  с ним; перезапуск демона, отложенный из-за занятых чатов, сделает следующий запуск.
- **«Продолжить в другом агенте»** (меню чата; под ошибкой о лимитах — кнопкой): новый чат с выбранным агентом в той же папке,
  вся история — файлом во вложении (сообщения дословно, команды и правки кратко, git в конце), новый агент пересказывает, где
  остановились, и ждёт команды. Историю читаем с диска — лимиты исходного агента не нужны. Плашки-связки в обоих чатах, значок ⇄.
  Проверено: Antigravity → Claude, Claude → Antigravity, Claude → Codex; окно — в браузере и на 375 px. Не проверено: кнопка
  под настоящей ошибкой лимита, iPhone.
- Antigravity: под законченным ответом больше не мигает каретка «пишет…» — конец истории иногда приходит после ответа на
  `session/load`, теперь он тоже считается историей (и чат не поднимается непрочитанным). Простаивающие сессии Antigravity
  больше не закрываются через 10 минут: закрытие у agy гасит фоновые задачи сессии.

## Известные ограничения

- iOS 27: система размывает верх приложения на экране «Домой»; лечится на телефоне — «Понижение прозрачности» (см. ARCHITECTURE).

- Текст мыслей Claude часто приходит пустым (только подпись) — показываем «размышления · ~N токенов», если есть оценка.
- Окно контекста модели Claude становится известно после первого ответа в процессе (`modelUsage.contextWindow`), до этого
  показываются только токены.
- Перезапуск `mcc-agentd` обрывает идущие ходы и фоновые задачи (история при этом сохраняется в файлах CLI).
- Один и тот же чат нельзя одновременно вести из терминала и из веба — оболочка это замечает и показывает баннер.
- Telegram: свой ответ (текстом) на вопрос и замечания к плану — только в вебе.
